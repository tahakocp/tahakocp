### Hi, I'm Taha

I build small, tested tools for the places where software meets hardware: microcontrollers, FPGAs, robots and things you can print. Each repo tries to do one job, says what was measured, and says what was not.

| project | what it does |
|---|---|
| [lastwords](https://github.com/TahaKocpinar/lastwords) | The last log lines and the fault that killed your Cortex-M, still in RAM after the reset. Two C files. |
| [urdflint](https://github.com/TahaKocpinar/urdflint) | Catches broken URDF robot descriptions before your simulator does. One Rust binary. |
| [hollowstar](https://github.com/TahaKocpinar/hollowstar) | Tells whether a GitHub repo's stars were earned or bought, from public data only. |
| [tinyraster](https://github.com/TahaKocpinar/tinyraster) | Triangle rasterizer in SystemVerilog, pixel-exact against a C model. |
| [planet17](https://github.com/TahaKocpinar/planet17) | Parametric 3D-printable planetary gearbox for NEMA 17 steppers, with collision checks in CI. |
| [alertpages](https://github.com/TahaKocpinar/alertpages) | Earthquake and disaster alerts relayed by GitHub Actions to an offline web page and Telegram. No server. |

Hardware projects here are verified in simulation unless the README says otherwise. If you build one for real, I would like to hear how it went: open an issue in that repo.
